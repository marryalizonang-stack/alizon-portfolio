# Alizon — Portfolio Website

One-page portfolio for Marry Alizon Ang: executive support, STR/Airbnb management, recruitment, operations and creative design.

## Files
- `index.html` — the whole site (styles and scripts included)
- `images/` — portraits, portfolio pages and client logos

## Publish with GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
The site goes live at `https://<username>.github.io/alizon-portfolio/`.

## Contact form
Inquiries are sent to the Google Sheet web app set in `FORM_ENDPOINT` near the bottom of `index.html`.
Until that URL is filled in, the form falls back to opening the visitor's email app addressed to maryalizonang@gmail.com.
